# 访问宿主机上的模型服务

如果模型服务仅监听宿主机的 `127.0.0.1`，Docker 容器中的同一地址无法访问它。可以在 Linux 开发机上运行 `model-relay.py`，将 Docker 网桥地址上的端口转发到宿主机的本地端口。

1. 用 `docker network inspect bridge` 确认默认网桥的网关地址，并确认目标服务和监听端口。示例使用 `172.17.0.1:18317` 转发到 `127.0.0.1:8317`；不要绑定 `0.0.0.0`。
2. 根据 `model-relay.service.example` 修改用户名、项目路径和端口，安装为 systemd 系统服务，并启用服务。模型服务本身也需要独立配置为开机启动。
3. 在网页的模型配置中使用网关地址，例如将 `http://127.0.0.1:8317/v1` 改为 `http://172.17.0.1:18317/v1`。地址变化后按页面要求重新填写 API Key。
4. 从 Worker 的网络中验证模型接口可达，并执行一次分类测试。修改 Docker 默认网桥地址后，需要同步更新转发服务和模型接口地址。

转发只绑定指定的网桥地址，但能访问该网桥地址的容器或主机进程仍可能访问此端口。模型服务应保持身份校验；HTTP 流量在本机网桥上不加密。
