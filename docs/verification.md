## 复现

按 [README](../README.md) 准备依赖与测试数据库后运行：

```sh
make check
script/gen-client.sh --check
```

测试数据库账号需要创建 schema 和 `pg_trgm` 扩展的权限。`AGENTOWL_TEST_DATABASE_URL` 未设置时，数据库测试会跳过；只有明确提供测试数据库的运行结果才能作为集成验证依据。`make ci` 额外要求数据库、Docker Compose 和 Kiota 均可用，缺失时直接失败。

本地服务启动后的 HTTP 冒烟命令及平台接入步骤分别见 [README](../README.md) 和 [运行手册](operations.md)。开发机验收脚本位于远端项目目录下的 `deploy/verify-dev-deployment.py`；其验证对象是实际容器与 HTTPS 入口。
